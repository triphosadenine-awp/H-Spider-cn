# H-Spider-cn

[English](README_EN.md) | 简体中文

这是一个简单的爬虫，通过伪装能够爬取静态链接与图片资源，本工具为安全工具，切勿用于爬取官方网站，否则后果自负，本人已在1.3版本
新加入自动网站扫描与简单SQL注入，后续开发进度较慢，有bug请联系我们

## 软件下载
软件已打包成独立的 Windows 软件（含 Python 环境），**推荐直接下载压缩包使用**：
[点击这里下载 H-Spider-v1.4.zip](https://github.com/triphosadenine-awp/H-Spider-cn/releases/tag/v1.4)

如果想单独下载 exe 文件：
[点击这里下载 pc.1.4.exe](https://github.com/triphosadenine-awp/H-Spider-cn/releases/tag/v1.4)

**使用说明：**
1. 下载压缩包并解压。
2. 双击 `pc.exe` 运行。
3. **注意**：部分杀毒软件（火绒、360等）可能会误报

## 源码运行
如果你想看代码是怎么写的，可以查看仓库中的 `pc.py` 
运行源码需要自行安装 Python 环境
